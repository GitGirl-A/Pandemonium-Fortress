# Web Search

This file documents web search capabilities and integrations for the Pandemonium-Fortress project.

## Overview

Web search functionality enables the app to query external sources for real-time information, supporting investigation workflows and digital security operations.

## Use Cases

- Searching for scammer profiles and digital footprints
- Cross-referencing suspect identities across public sources
- Gathering open-source intelligence (OSINT) for active cases
- Verifying claims made by subjects under investigation

## Integration Notes

- Queries should be scoped to publicly available data only
- Results must be logged and attributed to their source
- All search activity is subject to applicable privacy laws and platform terms of service
